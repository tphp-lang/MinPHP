# 评估后明确不做

留下结论与理由，避免将来重复论证。新增条目须写清"为什么不做"与"什么条件下可重启评估"。

## object 类型

**已支持（有边界）。**

- 落地前提：**流敏感类型收窄**已实现（见下节）——它是零运行时下让 `object` 可用的唯一补救手段
- 支持形态：C 表示为裸对象指针 `TphpObjHead *`；**类 → `object`** 零成本上转、**接口 → `object`**
  取 `.obj` 字段；`object` 参与引用计数，可作形参 / 返回 / 字段 / 局部 / `array<T>` / `map<K,V>` / `catch` 的类型
- **硬边界**：`object` 无方法 / 字段布局，直接成员访问是编译错误，**必须先 `instanceof` 收窄回具体类**；
  且**只能收窄回具体类**——`object` → 接口需要运行期 itab 查表，仍不做
- 注：运行期 `instanceof` 判定本身**不违背**零运行时——已由 `TphpVTHead` 静态表零成本支持
- 曾经不做（存档）：AOT 下静态类型一旦擦除为 `object`，方法槽位**编译期不可求**：类/接口的方法分发靠
  `TPHP_VT`（需编译期 vttype）+ itab，而 `object` 既不携带方法集写头，值内也没有分发入口，
  故 `$o->m()` 无法发射；PHP 的 object 语义（任意对象、可动态分发）无法对齐
- 纯"不透明句柄"（不外传类型、不调成员）场景仍由 phpc 的 `c.ptr` 覆盖（且能传回 C 侧使用）
- 对照：对象域里与 `callable` 同构的是**接口值** `TphpIface{obj, itab}`——操作集大小 k 固定，
  且每个操作的入口都在值里；`object` 则「方法集写头」与「值内入口」二者皆无（收窄恢复了前者）

## object 专表"纯匿名类"

**不做。**

- 死句柄：`object` 本身无成员布局，须 `instanceof` 收窄回**具体类**才能用；而纯匿名类没有可写的类型名，
  无从收窄（`object` 支持后此点依旧成立）
- 注：匿名类**现已支持**，但它**不依赖** `object`——本语言强制匿名类 `implements` 至少一个具名接口
  （见 `doc/grammar.md`），故其类型始终可写、可跨边界传递，无需 `object` 擦除
- 只解决"语法可写"，不解决"可用" —— 净收益为零

## 匿名类

**已支持。**

- 触发重启：**闭包同构范式**——对象域里与 `callable`（`Callable{fn, env}`）同构的是**接口值**
  `TphpIface{obj, itab}`（操作集大小 k 固定、入口随值传递），这给匿名类提供了可用的跨边界传参形态
- 落地方式：**强制 `implements` 至少一个具名接口**（`new class { ... }` 与仅 `extends` 无 `implements`
  的形式均编译报错）；Parser 将 `new class implements I { ... }` **升格**为合成 `ClassDecl`，
  并入文件声明列表，复用既有类链路（Checker / Gen），几乎零改动
- 传参三条通道：① 构造参数喂入；② 本地使用合成类静态类型；③ 跨边界以 `implements` 的**具名接口**
  作为形参类型（本语言**没有**闭包式"可回填的擦除形参写头"，故不能用 `object` / 结构类型接收）
- 无 `use` 捕获、无 `env`：捕获外层值只能经构造参数存为属性
- 原"不做"理由（保留存档）：唯一有价值的形态（`extends` / `implements`，也是 PHP 主流用法）
  本可由**就近的普通类**零成本替代（TinyPHP 多文件合并单 TU）；纯匿名类仅局部推断可用，
  跨边界（参数/返回/字段）**无类型可写**
- **重启条件（已满足）**：测试框架 / mock 需求明确时，评估"强制父类型"方案
  （要求匿名类必须 `extends` 或 `implements`，使类型总是可写且可用）——现按"强制 `implements`"落地

## 流敏感类型收窄

**已支持。**

- 价值：对 `instanceof` 的直接增强 —— `if ($x instanceof Dog) { $x->fetch(); }`
  不再报错"类 Animal 没有方法 fetch()"；同时是 `object` 类型的**前置条件**（见上节）
- 生效形态：if 正分支、守卫子句 `if (!($x instanceof C)) { return; }`、`&&` 右侧、三元 then、
  `while` / `for` 条件体；语义为**分支局部、退出即失效**，对变量赋值会使其失效
- 边界：只能收窄回**具体类**（`object` / 接口 / 父类变量 → 具体类）；收窄目标为接口需运行期 itab，不做
- 实现：**纯编译期** —— Checker 写入收窄影子 `VarSymbol`（沿作用域父链查找）+ Gen 零成本指针转型 /
  `.obj` 解包；**无运行期判定、无单态化、无运行期类型表**
- 注：与数值收窄（float → `c.f32`，用例 `16_narrow`）同名但**无关**
- 守卫须写 `!($x instanceof C)`：`!$x instanceof C` 因 `!` 要求 bool 操作数而是类型错误
